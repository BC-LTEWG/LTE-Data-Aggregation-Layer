# Instructions:
1. Clone the actual labor time economy repo, found [here](https://github.com/BC-LTEWG/Labor-Time-Economy-Simulation). Follow the instructions there to create a binary. 
2. Download and install the latest release of Overseer, found [here](https://github.com/alexbcreiner0/Overseer)
3. Run it once. This will create a folder in your user documents folder of the same name as the app.
4. Inside of that folder is a folder called models. Clone this repo directly into that folder. Alternatively, create a folder in that directory and copy-paste all of the contents from this repo into it.
5. Run the app. Under Demos, you should now see the option 'BC-LTE'. Select it and click 'Load Demo'. (THE SIMULATION WILL FAIL. THIS IS EXPECTED.)
6. In the control panel (left), at the top, you should see an entry labelled 'Binary path'. Click the elipsis icon to the right and select the binary that you created in step 1.

The simulation should begin running automatically! To save the choice of binary so as to not have to repeat step 5, in the menu bar select Parameters->Save Parameter Settings. Give it a name and confirm the save. Then, select File->Demo Settings. Select BC-LTE in the list, and then locate the 'Default preset' dropdown towards the bottom right. Click that and select the preset you created. Click Apply or Save to confirm the changes. After this, loading the BC-LTE demo will always select your binary automatically. Additionally, you can set it as the default to open with Overseer from this same menu.
