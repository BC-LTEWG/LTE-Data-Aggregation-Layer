# Instructions:
1. Download and install the latest release of Dr. Creiner's Modeling Tools, found [here](https://github.com/alexbcreiner0/Modeling-Tools)
2. Run it once. This will create a folder in your user documents folder of the same name as the app.
3. Inside of that folder is a folder called models. Clone this repo directly into that folder. Alternatively, create a folder in that directory and copy-paste all of the contents from this repo into it.
4. Select the model in the list once it appears, and click Open in editor to open it (you can change in the global settings the IDE that the app will attempt to open). Or just open the file `/simulation/simulation.py`, however you want.
5. In that file, change the `EXE_PATH` to point at the location of your LTE's `/bin/sim` binary.
6. Run the app. Go to File->Settings->Demos. Click the +Demo button. Give the demo a display name.
7. In the simulation model dropdown select the folder you created/cloned in your Documents/models folder. The rest of the settings should auto-select.
8. Click Save (The one on the upper left). Then after that, click either Apply or the other Save button.
9. Click Demos->Whatever display name you gave->Load demo.
